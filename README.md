# Pooja & Shubham Wedding Invitation

Interactive React/Vite wedding invitation opening page.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Build

```bash
npm run build
```

The opening screen uses the supplied P&S logo as the clickable seal. Clicking/tapping it animates the envelope flap and transitions into the invitation page.
